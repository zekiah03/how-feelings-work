# 感情状態遷移ネットワークの理論的基盤
## ── ノード・エッジ・遷移条件の形式モデル ──

**草稿 v1.0 ／ 2026年5月**

---

## 概要

本稿は、人間の感情経験をネットワークとして形式化するための理論的枠組みを提案する。感情を「状態ノード」として、感情間の移行を「有向エッジ」として表現し、各ノードには次元座標・評価構造・時間的プロファイルを、各エッジには遷移型・遷移条件・中介変数を付与する。本枠組みは、ラザルスの認知的評価理論、バレットの構成主義的感情理論、シェラーのコンポーネント・プロセス・モデル、クッペンスらの動的システム理論を統合し、単一の表現可能な形式モデルへと収束させることを目的とする。

---

## 第1章　なぜ「ネットワーク」か

感情研究の主要なパラダイムはいずれも、感情の「点」的な記述には優れているが、感情が「どこから来てどこへ向かうか」という動的な側面の形式化を苦手とする。

基本感情論（エクマン, 1972）は離散的カテゴリを与えるが、カテゴリ間の移行を記述する文法を持たない。円環モデル（ラッセル, 1980）は二次元座標を与えるが、座標空間内の「なぜその方向に動くか」を説明しない。認知的評価理論（ラザルス, 1991）は遷移の認知的条件を詳述するが、経路の数学的な構造化には至っていない。動的システムアプローチ（クッペンス他, 2010）は時系列ダイナミクスを記述するが、個別感情の内容的特性が薄れる。

本稿のネットワーク形式モデルは、これらの視座を「ノード＝感情状態」「エッジ＝遷移」として統合することで、内容的豊かさと構造的明示性を両立させる。具体的な応用は感情教育・心理療法・感情リテラシー訓練における可視化ツールである。

## 第2章　ノードの形式的構造

各感情ノード *E_i* は以下の7つの属性タプルで定義される。

```
E_i = (Cat_i, Dim_i, App_i, Temp_i, Body_i, Func_i, Reg_i)
```

### 2.1　カテゴリ属性 Cat_i

感情を4つの機能的カテゴリに分類する。

| カテゴリ | 定義 | 代表例 |
|---|---|---|
| **basic** | 進化的に保存された、文化普遍的な表情・行動傾向を持つ基本感情 | 喜び、悲しみ、怒り、恐怖、驚き、嫌悪 |
| **positive** | ポジティブなヴァレンスを持ち、資源形成・拡張機能を担う感情 | 愛情、感謝、誇り、希望、畏敬、フロー |
| **negative** | ネガティブなヴァレンスを持ち、警報・適応を担う感情 | 不安、悲嘆、後悔、退屈、寂しさ、焦燥 |
| **social** | 自己と他者の比較・評価から生じる自己意識感情 | 恥、罪悪感、嫉妬、共感、軽蔑、困惑 |

### 2.2　次元属性 Dim_i ── 拡張円環モデル

ラッセル（1980）の二次元モデルを三次元に拡張する。

```
Dim_i = (V_i, A_i, D_i)
```

- **V（Valence）**: 快−不快軸。−2（強い不快）〜＋2（強い快）
- **A（Arousal）**: 覚醒−沈静軸。−2（強い沈静）〜＋2（強い覚醒）
- **D（Dominance）**: 支配−服従軸（メーラビアンのPADモデルより）。D＋は「自分がコントロールしている感覚」、D−は「コントロールされている感覚」。怒りはV−だがD＋、恐怖はV−かつD−、という区別に重要。

三次元PAD空間内での感情の座標:

|---|---|---|---|
| 喜び | +2 | +1 | +1 |
| 怒り | -1 | +2 | +2 |
| 恐怖 | -2 | +2 | -2 |
| 悲しみ | -2 | -1 | -1 |
| 驚き | 0 | +2 | -1 |
| 嫌悪 | -2 | 0 | +1 |
| 不安 | -2 | +1 | -2 |
| 誇り | +2 | +1 | +2 |
| 恥 | -2 | 0 | -2 |
| 安心 | +2 | -1 | +1 |
| 好奇心 | +1 | +1 | +1 |
| 畏敬 | +1 | 0 | -1 |
| 焦燥 | -1 | +2 | -1 |
| 退屈 | -1 | -2 | -1 |
| 寂しさ | -2 | -1 | -2 |
| 愛情 | +2 | 0 | +1 |
| 感謝 | +2 | 0 | +1 |
| 後悔 | -1 | -1 | -1 |
| 失望 | -1 | -1 | -1 |
| コンパッション | +1 | 0 | +1 |
| 共感 | 0 | 0 | 0 |
| 嫉妬 | -2 | +1 | -1 |
| 羨望 | -1 | 0 | -1 |
| 罪悪感 | -1 | 0 | -1 |

### 2.3　評価属性 App_i ── シェラーの評価次元

シェラー（2005）のコンポーネント・プロセス・モデルに基づき、各感情の典型的な認知的評価プロファイルを定義する。評価は5次元で構成される。

```
App_i = (Nov_i, Pleas_i, Goal_i, Cope_i, Norm_i)
```

| 次元 | 記号 | 内容 | スケール |
|---|---|---|---|
| 新規性 | Nov | 出来事がどれだけ予測外か | 低/中/高 |
| 快楽的評価 | Pleas | 出来事が本人にとって快か不快か | 不快/中立/快 |
| 目標関連性 | Goal | 自分の目標・価値との一致・不一致 | 不一致/中立/一致 |
| 対処可能性 | Cope | 自分の力でこの状況を変えられるか | 低/中/高 |
| 規範適合性 | Norm | 社会規範・自己の価値観との適合性 | 違反/中立/適合 |

各感情の典型的評価プロファイル:

|---|---|---|---|---|---|
| 喜び | 中 | 快 | 一致 | 高 | 適合 |
| 悲しみ | 低 | 不快 | 不一致 | 低 | 適合 |
| 怒り | 低 | 不快 | 不一致 | 中 | 違反 |
| 恐怖 | 高 | 不快 | 不一致 | 低 | 中立 |
| 驚き | 高 | 中立 | 中立 | 中 | 中立 |
| 嫌悪 | 低 | 不快 | 不一致 | 中 | 違反 |
| 不安 | 中 | 不快 | 不一致 | 低 | 中立 |
| 誇り | 低 | 快 | 一致 | 高 | 適合 |
| 恥 | 高 | 不快 | 不一致 | 低 | 違反 |
| 罪悪感 | 低 | 不快 | 不一致 | 中 | 違反 |
| 希望 | 中 | 快 | 一致 | 中 | 適合 |

| 嫉妬 | 中 | 不快 | 不一致 | 低 | 中立 |
| 軽蔑 | 低 | 不快 | 不一致 | 高 | 違反 |

### 2.4　時間的属性 Temp_i

感情の時間プロファイルを4つのパラメータで記述する。

```
Temp_i = (Onset_i, Peak_i, Decay_i, Persist_i)
```

| パラメータ | 記号 | 意味 | 単位 |
|---|---|---|---|
| 立ち上がり速度 | Onset | トリガーから最大強度までの時間 | 秒/分 |
| ピーク持続 | Peak | 最大強度が維持される典型的時間 | 秒/分/時間 |
| 減衰特性 | Decay | 急速(rapid)/緩徐(gradual)/慢性(chronic)/波動(wave) | 分類 |
| 持続傾向 | Persist | 反芻なしでの典型的持続時間 | 分/時間/日 |

各感情の時間プロファイル:

| 感情 | Onset | Peak | Decay | Persist |
|---|---|---|---|---|
| 喜び | 秒単位 | 秒〜数分 | rapid | 数分〜数時間 |
| 驚き | 0.2秒 | 0.5〜2秒 | rapid | 数秒 |
| 恐怖 | 0.1秒 | 秒〜分 | gradual | 分〜時間 |
| 怒り | 秒単位 | 秒〜20分 | gradual | 20〜30分（反芻なし） |
| 悲しみ | 分単位 | 分〜時間 | wave | 時間〜日 |
| 嫌悪 | 秒単位 | 秒〜分 | rapid | 分 |
| 不安 | 分単位 | 時間〜日 | chronic | 時間〜週 |
| 後悔 | 分〜時間 | 時間〜日 | wave | 日〜年 |
| 退屈 | 分単位 | 時間 | gradual | 時間 |
| 寂しさ | 時間単位 | 日 | chronic | 日〜月 |
| 悲嘆 | 時間〜日 | 週 | wave | 月〜年 |
| 安心 | 秒単位 | 秒〜分 | rapid | 分〜時間 |
| 誇り | 分単位 | 分〜時間 | gradual | 時間〜日 |
| 恥 | 秒単位 | 分〜時間 | wave | 時間〜年 |
| 畏敬 | 秒〜分 | 分〜時間 | gradual | 時間〜日 |
| フロー | 分単位 | 時間 | gradual | 活動中 |

### 2.5　身体・神経属性 Body_i

主要な神経伝達物質・脳領域・自律神経プロファイルを記述する。

```
Body_i = (NT_i, Brain_i, ANS_i, Face_i)
```

- **NT**: 主要神経伝達物質・ホルモン
- **Brain**: 主要脳領域（機能的役割と共に）
- **ANS**: 自律神経のパターン（交感神経/副交感神経のバランスと特性）
- **Face**: 表情の構成要素（AU: Action Units、FACoding準拠）

### 2.6　機能属性 Func_i

感情の進化的・社会的機能を分類する。

```
Func_i = (ActionTend_i, SocialSig_i, CognEffect_i)
```

| サブ属性 | 内容 |
|---|---|
| ActionTend（行動傾向） | 接近/回避/攻撃/凍結/養育/探索/助けを求める |
| SocialSig（社会的シグナル） | この感情の表出が他者に何を伝えるか |
| CognEffect（認知への影響） | 注意・記憶・判断に与える特徴的な影響 |

### 2.7　調整属性 Reg_i

感情調整の主要戦略とその推奨介入タイミングを記述する。

```
Reg_i = (PreResp_i, ReAppra_i, PostResp_i, Contraind_i)
```

| サブ属性 | 内容 |
|---|---|
| PreResp | 反応前の介入：状況選択・注意の再配置 |
| ReAppra | 認知的再評価の具体的方向性 |
| PostResp | 反応後の対処：体験的受容・表出・修復行動 |
| Contraind | 逆効果になりやすい方略（禁忌） |

## 第3章　エッジの形式的構造

エッジ *e_{ij}* は、感情状態 *E_i* から感情状態 *E_j* への遷移を表す。

```
e_{ij} = (Type_ij, Cond_ij, Med_ij, Prob_ij, Speed_ij)
```

### 3.1　遷移型分類 Type_ij

遷移を6つの型に分類する。

| 型 | 記号 | 定義 | 例 |
|---|---|---|---|
| **急性遷移** | ACUTE | トリガーへの即時評価変化により秒〜分単位で遷移する | 驚き→恐怖、驚き→喜び |
| **評価的遷移** | APPR | 認知的再評価（帰属の変化）によって遷移する | 悲しみ→怒り（「不当だ」という再評価） |
| **強度遷移** | INTENS | 同一感情の強度変化で隣接感情へ変質する | 苛立ち→怒り→激怒 |
| **慢性遷移** | CHRONIC | 長期持続により感情が質的に変容する | 不安（慢性）→抑うつ、悲しみ→悲嘆 |
| **解消遷移** | RESOLV | 問題解決・受容・修復により感情が解消・変容する | 恐怖→安心、罪悪感→感謝（赦し後） |
| **混合遷移** | BLEND | 2つの感情が同時に存在し二価感情を形成する | 悲しみ＋喜び→ノスタルジア |

### 3.2　遷移条件 Cond_ij

エッジが活性化される認知的・文脈的条件。シェラーの評価次元に基づく「評価変化」として形式化する。

遷移条件は「先行感情 *E_i* の評価プロファイルのどの次元がどのように変化したか」として記述される。

```
Cond_ij = {△Nov, △Pleas, △Goal, △Cope, △Norm, ContextReq}
```

代表的な遷移条件の例:

| エッジ | 条件 |
|---|---|
| 悲しみ→怒り | △Goal: 不一致の原因が「不当性」として帰属される（△Norm: 違反認知の追加） |
| 怒り→罪悪感 | △Norm: 自分の行為が自己の価値観に違反したと認識 |
| 恐怖→不安 | △Nov: 脅威対象が曖昧化、△Cope: 対処見通しが低下 |
| 不安→希望 | △Cope: 中程度の対処可能性の認識 |
| 恥→怒り | 評価の対象が自己→他者へ転換（防衛的外在化） |
| 喜び→誇り | △Goal: 達成が自己の能力・努力に帰属される |

### 3.3　中介変数 Med_ij

同じ先行感情でも遷移先が分かれるとき、その分岐を決定する変数。

```
Med_ij = {AttribStyle, CopeCap, SocialSup, BioState, CulturalNorm}
```

| 中介変数 | 記号 | 内容 |
|---|---|---|
| 帰属スタイル | AttribStyle | 内的/外的、安定/不安定、全般的/特定的帰属の傾向 |
| 対処能力 | CopeCap | 感情調整スキル・問題解決スキルの水準 |
| 社会的支援 | SocialSup | 利用可能な社会的資源の量と質 |
| 生物学的状態 | BioState | 睡眠・栄養・ホルモン・疾患による感情閾値の変動 |
| 文化的規範 | CulturalNorm | 感情表出の規範、感情語彙の利用可能性 |

**分岐の例：「失敗」後の遷移**

```
失敗（トリガー）
    │
    ├─[AttribStyle: 内的・安定・全般的]→ 恥 → 隠蔽 → 孤立 → 抑うつ
    │
    ├─[AttribStyle: 内的・不安定・特定的]→ 罪悪感 → 謝罪 → 修復
    │
    ├─[AttribStyle: 外的]→ 怒り → 他責
    │
    └─[CopeCap: 高, SocialSup: 有]→ 失望 → 再評価 → 希望 → 再挑戦
```

### 3.4　遷移確率 Prob_ij と遷移速度 Speed_ij

```
Prob_ij ∈ [0, 1]  : 先行感情E_iが生じたとき、E_jへ遷移する集団的確率
Speed_ij ∈ {急速, 漸進, 慢性}
```

確率は個人差・文化差・文脈によって大きく変動するため、集団的確率を「規範的な基準値」として使用し、個人の中介変数による補正を行う。

## 第4章　遷移カスケードの形式化

### 4.1　カスケード定義

カスケード *C* は、感情ノードの時系列的連鎖である。

```
C = E_{i1} →^{e_{i1,i2}} E_{i2} →^{e_{i2,i3}} E_{i3} → ... → E_{in}
```

各遷移は `e_{ij}` で定義されたエッジ属性を保持する。

### 4.2　カスケードの4分類

| 分類 | 特性 | 典型例 |
|---|---|---|
| **建設的カスケード** | 最終ノードがより高いV、またはより高いCope状態 | 不安→計画→希望→達成→喜び→誇り |
| **破壊的カスケード** | 最終ノードがより低いV・低いCope状態（悪循環） | 失望→恥→隠蔽→孤立→抑うつ |
| **振動カスケード** | 二状態間を往復するループ | 不安→一時的安心→不安（強迫的確認）|
| **安定化カスケード** | 高強度から低強度・高V状態への収束 | 怒り→冷却→失望→受容→静謐 |

### 4.3　カスケード介入点の理論

カスケードの経路を変更するには、**分岐点（branching point）**での介入が最も効果的である。分岐点は以下の条件で識別される。

1. **複数の出力エッジが存在する**：同一先行感情から複数の遷移が可能
2. **中介変数が出力先を決定している**：介入によって中介変数を変更できる
3. **遷移速度が漸進的（CHRONIC以外）**：介入の時間的余裕がある

**代表的介入法とその機序**

| 介入法 | 標的分岐点 | 変更する中介変数 | メカニズム |
|---|---|---|---|
| 認知的再評価 | 悲しみ/失望の後 | AttribStyle | 帰属のパターンを変える |
| 問題解決訓練 | 不安の初期 | CopeCap | 対処可能性の認知を高める |
| 社会的支援活用 | 悲嘆・孤独 | SocialSup | 外部リソースで対処負荷を下げる |
| 身体的介入（呼吸・運動） | 怒り・不安のピーク時 | BioState | 生理的覚醒を低下させる |
| マインドフルネス | 反芻ループ | CopeCap | 思考の脱中心化で振動カスケードを止める |
| セルフ・コンパッション | 恥→攻撃/抑うつ分岐 | AttribStyle | 自己全体への帰属を行為への帰属へ転換 |

## 第5章　調整理論の統合モデル

### 5.1　グロスの感情調整モデルとネットワーク理論の統合

グロス（1998）の感情調整モデルは「感情生成過程のどの段階で介入するか」を5段階で記述する。本稿のネットワーク形式モデルでは、これをエッジの「介入可能段階」として再解釈する。

```
感情生成過程:
状況選択 → 状況修正 → 注意の再配置 → 認知的再評価 → 反応調整
   ↕           ↕            ↕                ↕              ↕
[前向き介入]             [中間介入]        [最有効介入]    [最後の手段]
```

| 段階 | ネットワーク対応 | 有効性 | 注意点 |
|---|---|---|---|
| 状況選択 | トリガーとなるノードへのエッジを避ける | 高（予防的） | 回避が過度になると悪循環 |
| 状況修正 | トリガー条件を変更し別のエッジを活性化する | 中 | 常に可能とは限らない |
| 注意の再配置 | 評価プロセス前の注意制御 | 中 | 反芻とは逆の方向性が必要 |
| 認知的再評価 | Cond_ij の帰属次元を変更する | 高（健全） | 早い段階ほど効果的 |
| 反応調整（抑圧） | ノードの表出を止めるが状態は持続 | 低〜逆効果 | 身体化・受動的攻撃のリスク |

### 5.2　感情粒度と遷移解像度

バレット（2017）の「感情粒度（emotional granularity）」概念は、本モデルにおいて重要な意味をもつ。

感情粒度が高い個人は：
- 感情ノードをより細かく区別できる（「不安」と「焦燥」を別ノードとして認識する）
- 遷移条件をより精確に同定できる
- 適切な感情調整戦略を選択しやすい
- 精神的健康指標と正の相関を示す（Kashdan et al., 2015）

感情粒度が低い個人は：
- 複数の感情を「嫌な気分」として一括りにする（粗いノード表現）
- 遷移の分岐点を見逃しやすい
- 調整戦略の選択が非効率になりやすい

**教育的含意**: 本ネットワーク可視化ツールは、感情ノードの明示的提示によって感情粒度を高める訓練的機能をもつ。感情ラベリング（affect labeling）は、島皮質活動の増大と扁桃体活動の減少を引き起こし、感情処理の皮質的制御を強化する（Torre & Lieberman, 2018）。

## 第6章　特定の重要遷移の詳細分析

### 6.1　怒りの二経路モデル

怒りは、先行感情と帰属スタイルによって二つの主要経路に分岐する。

**経路A：防衛的怒り（外在化）**
```
恥 → [防衛的外在化：Norm-違反の帰属先を他者へ転換] → 怒り(Narcissistic) → 攻撃
```
これはナルシシスト的怒り（narcissistic rage）の典型的機序であり、恥の回避としての怒り表出である。治療的に「怒りの下にある恥」へのアクセスが鍵となる。

**経路B：意味のある怒り（道徳的憤り）**
```
価値の侵害認知 → [不当性評価：Norm-違反の外部帰属] → 義憤 → 向社会的行動
```
この経路の怒りは、社会変革・正義追求の動力となる。抑制すべきではなく、建設的表出に変換することが目標となる。

### 6.2　不安の自己強化ループと離脱条件

不安には特有の自己強化機序がある。

```
不安
  │
  ├─[注意の脅威への偏向]
  │    ↓
  │  脅威情報の選択的収集
  │    ↓
  │  不安の増強
  │    ↓
  │  回避行動
  │    ↓
  │  短期的安心（強化）
  │    ↓
  └──→ 不安のベースラインが上昇（悪循環）
```

**離脱条件**（曝露療法の機序）:
- 回避を行わず、安全な文脈で不安状態を維持する
- 「予測していた災害」が起きないという「新しい学習」を形成する
- 脅威記憶の「上書き」ではなく、安全記憶との「競合的抑制」が生じる

これは純粋な消去（extinction）ではなく、「恐怖記憶と安全記憶の並列保存」であり、ストレス下での再発(return of fear)を説明する。

### 6.3　恥と罪悪感の分岐モデル

タングニー（2003）の研究を本モデルで形式化する。

```
道徳的失敗/社会規範違反
        │
        ├─[帰属=自己全体：「私はダメな存在だ」]
        │    → 恥 (V:-2, A:0, D:-2)
        │       ├─ 隠蔽/逃避 → 孤立 → 抑うつ
        │       ├─ 外在化 → 怒り → 攻撃
        │       └─ [Shame Resilience:恥を認め共有する]
        │                → 罪悪感的処理への転換 → 修復
        │
        └─[帰属=自己の行為：「私は悪いことをした」]
             → 罪悪感 (V:-1, A:0, D:-1)
                └─ 謝罪/修復行動 → 解消 → 安堵 → 関係強化
```

**治療的含意**: ブレネー・ブラウン（2012）のShame Resilienceは、「恥→罪悪感的処理への転換」を促す構造的介入として理解できる。具体的には：
1. 恥を認識する（感情ラベリング）
2. 信頼できる他者と共有する（社会的支援）
3. 批判的な自己物語を問い直す（認知的再評価）
4. 共通の人間性を認識する（セルフ・コンパッション）

### 6.4　悲嘆の二重過程モデルの形式化

シュトロエベとシュット（1999）の二重過程モデルをネットワーク理論で形式化する。

悲嘆は二つのノード集合間の振動として特徴づけられる。

**喪失志向クラスタ** (LO: Loss-Oriented):
```
悲しみ ←→ 罪悪感 ←→ 思慕 ←→ 泣き/表出
```

**回復志向クラスタ** (RO: Restoration-Oriented):
```
不安 ←→ 希望 ←→ 誇り（新たな役割）←→ 静謐
```

健康な悲嘆過程：LO と RO の間を振動しながら、LO 滞在時間が徐々に減少し、RO 滞在時間が増加する。

病理的悲嘆（遷延性悲嘆症）：LO クラスタへの固着、RO への遷移が発生しない状態。

## 第7章　文化差と普遍性の統合フレームワーク

### 7.1　ハイブリッドモデルの提案

基本感情論（エクマン）と構成主義（バレット）の論争に対して、本稿は「進化的核 ＋ 文化的外層」のハイブリッドモデルを採用する。

```
感情ノードの構造:
┌──────────────────────────────────┐
│  文化的外層（Cultural Shell）      │
│  ・感情ラベル（言語）               │
│  ・表出規則（display rules）        │
│  ・経験のスクリプト                 │
│  ┌────────────────────────────┐  │
│  │  評価的中間層（Appraisal Core）  │  │
│  │  ・認知的評価パターン             │  │
│  │  ・シェラーの5次元               │  │
│  │  ┌──────────────────────┐  │  │
│  │  │  進化的核（Biological Core）  │  │
│  │  │  ・コア・アフェクト（V×A）    │  │
│  │  │  ・自律神経反応               │  │
│  │  │  ・行動傾向                   │  │
│  │  └──────────────────────┘  │  │
│  └────────────────────────────┘  │
└──────────────────────────────────┘
```

このモデルの予測：
- 進化的核（コア・アフェクト）は文化普遍的
- 評価的中間層は部分的に普遍的（基本評価次元）、部分的に文化可変
- 文化的外層は高度に文化可変（感情語彙、表出規則）

### 7.2　翻訳困難な感情の位置付け

翻訳困難な感情語彙（語彙のない感情）は、文化固有の「文化的外層」が「評価的中間層」を独自に切り出したものとして理解できる。

| 語彙 | 言語 | 対応するPAD座標（推定） | 評価的特徴 |
|---|---|---|---|
| Saudade | ポルトガル語 | V:0, A:-1, D:-1 | 不在への切望、諦め混じりの温かさ |
| Schadenfreude | ドイツ語 | V:+1, A:0, D:+1 | 他者の失敗への密かな満足（罪悪感混じり） |
| 甘え | 日本語 | V:+1, A:-1, D:-1 | 他者への依存許容への安心と喜び |
| ハン（恨）| 韓国語 | V:-1, A:-1, D:-2 | 抑圧された不満・恨みの昇華不全 |
| Hygge | デンマーク語 | V:+2, A:-2, D:0 | 親密な場の静謐な幸福 |
| Mono no aware | 日本語 | V:0, A:-1, D:-1 | 儚さの認識からの悲しみ＋美 |

## 第8章　内受容感覚と感情粒度の関係

### 8.1　内受容感覚の役割

セス（2013）の「内受容予測符号化（interoceptive predictive coding）」理論によれば、感情経験は脳による身体内部状態の予測から生成される。本モデルへの含意は大きい。

```
内受容的予測信号（脳→身体）
         ↓
身体からの実際の信号（身体→脳）
         ↓
「予測誤差」が感情的文脈と照合される
         ↓
感情ラベルが付与される（構成主義的プロセス）
```

内受容感覚の精度（interoceptive accuracy）が高い人は：
- 身体信号をより正確に読み取れる
- 感情を身体レベルで区別できる
- 感情粒度が高い傾向がある

### 8.2　感情調整への実践的含意

感情粒度を高めるための具体的訓練は、本ネットワーク可視化ツールの設計に直結する。

| 訓練方法 | 機序 | ネットワークへの反映 |
|---|---|---|
| 感情ラベリング | 前頭前野による扁桃体活動の抑制 | 感情ノードに詳細なラベルを与える |
| 感情日記 | 感情の時系列追跡 | 自分が辿ったカスケード経路を意識化 |
| マインドフルネス | 評価なしの身体感覚観察 | 身体反応属性への注意を高める |
| 感情語彙の拡充 | 概念的分類の精緻化 | 翻訳困難な感情語彙の学習 |

## 第9章　本理論モデルの限界と今後の課題

### 9.1　確率的遷移行列の未実装

本モデルはノードとエッジの属性構造を定義したが、集団レベルの遷移確率行列（P_ij）の実証的推定はできていない。理想的には、EMA（Experience Sampling Method）データによる大規模縦断研究からP_ijを推定する必要がある。

### 9.2　個人差モデルの形式化の困難

中介変数（AttribStyle, CopeCap等）は個人差を生成するが、その個人差がP_ijをどのように変換するかの定量モデルは未完成である。ベイズ的アプローチによる個人適応型遷移予測モデルの開発が今後の課題である。

### 9.3　文化差の体系的組み込み

文化差は現在「文化的外層」として概念的に位置付けられているが、具体的にどの評価次元がどの文化でどう変わるかの体系的データは不足している。WEIRD偏向（欧米・高学歴・工業化・富裕・民主主義社会への偏り）の克服が必須である。

### 9.4　非線形ダイナミクスの未統合

動的システム理論（クッペンス他, 2010）との統合は概念的レベルにとどまっている。カオス理論・アトラクター理論・感情慣性（emotional inertia）の数学的概念と本ネットワークモデルの接続が必要である。

### 9.5　身体疾患との双方向モデル

慢性疾患→感情、感情→身体疾患の双方向関係は本モデルでは未実装である。炎症性サイトカイン・HPA軸・腸内細菌（gut-brain axis）を身体状態ノードとして感情ネットワークに統合した拡張モデルが求められる。

## 第10章　結論

本稿は、感情状態遷移ネットワークの形式的モデルを提案した。主要な貢献は以下の通りである。

1. **三次元PADモデル**: 従来の二次元モデルにDominance軸を追加し、怒りと恐怖、誇りと恥といった感情の区別に重要な制御感次元を導入した。

2. **評価プロファイル**: シェラーの5次元評価構造（新規性・快楽性・目標一致・対処可能性・規範適合性）を各感情ノードの内部構造として形式化した。

3. **6型遷移分類**: 急性・評価的・強度・慢性・解消・混合の6型によりエッジの多様な性質を区別した。

4. **遷移条件の形式化**: 「評価次元の変化」として遷移条件を記述し、認知的介入の対象を明示化した。

5. **中介変数の同定**: 帰属スタイル・対処能力・社会的支援・生物学的状態・文化的規範を分岐を決定する中介変数として特定した。

6. **カスケード理論**: 建設的・破壊的・振動・安定化の4カスケード型を定義し、介入点の理論的基盤を与えた。

7. **ハイブリッド文化モデル**: 「進化的核＋評価的中間層＋文化的外層」の3層構造により、普遍性と文化差を統合した。

本モデルは確率的遷移行列の実証的推定・個人差のベイズ的形式化・非線形ダイナミクスとの統合という課題を残すが、感情教育・心理療法・AI感情モデリングにおける可視化ツールの理論的基盤として十分な記述力を持つと考える。
